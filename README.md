# Замер скорости интернета

Небольшой консольный скрипт, который 10 раз последовательно скачивает указанный ресурс, дожидается полного ответа на каждый запрос и выводит:

- время и объём скачанных данных для каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- среднюю скорость скачивания.

В репозитории есть две реализации без сторонних зависимостей:

- `speed_test.py` — Python 3.9 или новее;
- `speed_test.js` — Node.js 18 или новее.

## Запуск Python-версии

```bash
python speed_test.py "https://example.com/large-image.jpg"
```

Необязательные параметры:

```bash
python speed_test.py URL --count 10 --timeout 30
```

- `--count` — количество последовательных запросов (по умолчанию `10`);
- `--timeout` — тайм-аут одного запроса в секундах (по умолчанию `30`).

## Запуск Node.js-версии

```bash
node speed_test.js "https://example.com/large-image.jpg"
```

Необязательные параметры совпадают с Python-версией:

```bash
node speed_test.js URL --count 10 --timeout 30
```

## Единицы измерения

- время запроса — секунды (`s`);
- объём данных — байты и мебибайты (`MiB`, где `1 MiB = 1 048 576 байт`);
- скорость скачивания — мебибайты в секунду (`MiB/s`).

Скорость рассчитывается как общий объём скачанных данных, разделённый на суммарное время всех запросов. На результат могут влиять настройки сети, нагрузка сервера, кэширование и выбранный ресурс.

## Тесты

Тест запускает локальный HTTP-сервер, поэтому доступ в интернет не требуется:

```bash
python -m unittest -v
```
